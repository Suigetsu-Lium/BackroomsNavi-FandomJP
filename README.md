\# BackroomsNavigationSystem\_FandomJP



Backrooms Fandom JP のローカルデータを利用して、Levelの検索・情報閲覧・画像閲覧・接続探索・ルート検索などを行うオフライン対応のナビゲーションシステムです。



\## 📥 ダウンロードと起動方法（ポータブル版）



本ソフトはインストーラーによるインストールが不要なポータブルアプリです。



1\. 画面右側にある \*\*「Releases」\*\*（または一番上の最新バージョン）をクリックします。

2\. `BackroomsNavi\_FandomJP\_vX.X.X.zip` というファイルをダウンロードします。

3\. ダウンロードしたZIPファイルを右クリックし、\*\*「プロパティ」\*\*を開きます。

4\. 全般タブの一番下にある \*\*「許可する」または「ブロックの解除」\*\* にチェックを入れて「OK」を押します。

&#x20;  （※Windowsのセキュリティ警告対策です。これを行わないと正常に起動しない場合があります）

5\. ZIPファイルを解凍し、中にある `BackroomsNavigationSystem\_FandomJP.exe` を実行してください。



\## 主な機能



\- Level検索 / 情報表示 / ローカル本文・画像の閲覧

\- Level間の接続探索 / ルート検索

\- 検索結果の保存

\- Fandom JPからHTMLのダウンロードおよび本文・画像情報の抽出

\- Levelネットワークの構築
